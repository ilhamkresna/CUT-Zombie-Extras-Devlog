## How to make another object sittable
1. In the Static Mesh Editor add a socket named `Seat` on the object's mesh: location = where the sitter's PELVIS (bone `Hips`) must end up (seat surface + pelvis height above buttock contact), socket X axis = direction the sitter faces. Save the mesh.
2. Make the object a set piece with a tag in the cinematic DA and point `JamSeat::SitObjectTag` (JamCinematicDirector.cpp, namespace `JamSeat`) at that tag; `JamSeat::SitterTag` names the cast member that sits. Any clip whose asset name contains `Sit` is aligned at its start; any other clip drops the offset.
3. No socket: the helper falls back to the top centre of the object bounds plus `PelvisAboveContactCm`.
